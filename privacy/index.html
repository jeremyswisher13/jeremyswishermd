Privacy and analytics

Privacy and analytics on this website.

This independent professional website uses cookie-free analytics only to understand which selected scheduling and educational actions help visitors take the next step.

Last updated July 30, 2026

At a glance

This site creates no patient profile.

  • Site analytics uses no cookies or persistent visitor identifiers
  • No names, symptoms, contact details, or form contents
  • Only five intentional action types are measured
  • Cookie-freeMinimal site analytics
  • IntentionalFive selected action types
  • RespectfulDNT and GPC honored

What is measured

Aggregate actions selected by visitors.

The site records an event when a visitor selects a phone link, the UCLA Health online appointment-request link, an exercise-program print button, referral instructions, or the button that loads an optional exercise video. Each event contains only the action type, the public page path, a broad placement such as navigation, hero, sidebar, content, contact, referral, or final call to action, and a timestamp used for aggregate reporting. Unknown addresses that reach the error page are grouped under the fixed path /404/ rather than recording the requested address.

Automatic pageview collection is disabled. The analytics configuration also omits referrers, campaign parameters, country or time-zone estimates, session IDs, time on page, scroll depth, user-agent details, screen size, viewport size, and browser language.

What is not collected

No personal or clinical information.

  • Names, email addresses, phone numbers, mailing addresses, or other contact details
  • Symptoms, diagnoses, medical-record information, insurance information, or form contents
  • The phone number selected, full destination URL, link text, URL query string, or page contents
  • This site's analytics does not set cookies or local-storage identifiers, use advertising identifiers, or create a profile of activity across pages or websites

This independent website does not provide a medical-message form, patient portal, or appointment form.

Third-party assets

Fonts, icons, and optional video players.

This site loads font and icon files from Google Fonts. When those files load, Google receives basic technical request information that may include an IP address and browser details. Google Fonts is not used by this site to identify visitors or measure scheduling activity.

Some home exercise pages offer an optional E3 Rehab video hosted by YouTube. No YouTube player, thumbnail, or video content is requested until a visitor selects Load video player. The player then uses YouTube's privacy-enhanced domain, youtube-nocookie.com. Loading or using it shares the page origin and technical request information, such as an IP address and browser details, with Google and YouTube. YouTube may use its own storage and policies after activation. The complete written exercise program remains available without loading a video.

Read Google's privacy policy

Analytics provider

Why Simple Analytics is used.

The site uses Simple Analytics for these limited events. Simple Analytics states that it does not store IP addresses, place cookies, fingerprint visitors, or create device identifiers. Optional analytics metrics are disabled. The provider processes essential technical fields plus the event name, public page path, and broad action placement needed to count each action. Visitors whose browsers communicate Do Not Track or Global Privacy Control are not measured by this site.

Read Simple Analytics privacy documentation
